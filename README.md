# ImageManipulation

An employee sent new images to use on a website, but there are a few issues:

1. The images are 90 degrees counter-clockwise
2. The images are too large, and should be resized to 128x128
3. The images are in the wrong format and should be .jpeg files

This program corrects those issues, and places the updated images in a folder called '/new_images' within the current working directory.
The folder containing the images also has to be in the same directory as the program. The image folder on this repository has some example images for testing.

-This program was created as part of the Google IT Automation Certification Course
